Frequently Asked Questions

General information about PixelCanvas Studio.

What is PixelCanvas Studio?

PixelCanvas Studio is an online collection of image, PDF and document tools for common tasks such as compression, resizing, conversion, cropping, OCR and PDF processing.

Are the tools free to use?

The website is designed to provide free access to its core tools. Individual tools may have their own processing limits or technical requirements, which will be explained on the relevant tool page.

Do I need to create an account?

Yes. PixelCanvas Studio uses account-based access so your profile, projects and other account features can be securely connected across devices.

What types of files are supported?

Supported formats depend on the tool. Common image formats include JPG, PNG and WebP, while PDF tools process PDF documents. Each tool page identifies the formats it supports.

Are uploaded files stored permanently?

PixelCanvas Studio is designed to use temporary file processing where server-side processing is required. File handling and deletion practices are described in the Privacy Policy and on relevant tool pages.

Can I use PixelCanvas Studio on my phone?

Yes. The website is designed to work on modern mobile browsers, tablets and desktop devices. Some tools may behave differently depending on the device and browser.

Can I download my processed result?

Yes. Tools that produce downloadable results provide a download option after processing is completed.

Can I share my result?

Where supported, you can use the device's sharing features or another available sharing option. Sharing availability can vary by browser and device.

Does PixelCanvas Studio guarantee passport-photo acceptance?

No. Passport and identity-photo requirements vary by country, authority, application type and submission method. Users should verify current requirements with the relevant authority before submitting a photo.

What should I do if a tool does not work?

Check that your file matches the supported format and size, try again, and use a current browser. If the problem continues, use the Contact page to report the issue.
